# Breakout

SDL3 と C++17 で作ったシンプルなブロック崩しゲームです。
効果音とボールの画像は外部ファイルを使わず、起動時にプログラムで生成しています。

## 特徴

- ブロック配置をテキストファイルで自由に作れる（6 種類、色ごとに得点が違う）
- パドルに当たった位置でボールの反射角が変わる（最大 60 度）
- 効果音（矩形波をその場で合成）
  - 発射音: 上昇する「ピュイッ」
  - パドル音: 低めの「ポン」
  - ブロック音: 短い「ピッ」。上の行ほど高い音
- 陰影とハイライト付きの球体ボール
- ライフ 3、ゲームオーバー / クリア後にリスタート可能

## 操作方法

| キー | 動作 |
|---|---|
| ← / → | パドルを左右に移動 |
| Space | ボールを発射 |
| R | リスタート（ゲームオーバー・クリア時） |
| Esc | 終了 |

## 必要なもの

- Windows 10 / 11（x64）
- Visual Studio 2022（「C++ によるデスクトップ開発」ワークロード）
- CMake 3.21 以上
- [vcpkg](https://github.com/microsoft/vcpkg)（`C:/vcpkg` に配置）
- SDL3

> **メモ:** vcpkg の場所は [CMakePresets.json](CMakePresets.json) の `toolchainFile` で `C:/vcpkg` に固定しています。
> 別の場所に置いている場合は、この値を書き換えてください。

## ビルドと実行

### 1. SDL3 をインストール

```powershell
C:\vcpkg\vcpkg.exe install sdl3:x64-windows
```

### 2. ビルド

```powershell
cmake --preset default
cmake --build --preset release   # Debug 版は --preset debug
```

### 3. 実行

```powershell
.\build\Release\breakout.exe
```

`SDL3.dll` はビルド時に vcpkg が実行ファイルの隣へ自動でコピーします。

### VS Code で開発する場合

C/C++ 拡張と CMake Tools 拡張を入れた状態でフォルダを開くと、`.vscode/` の設定が使われます。

| キー | 動作 |
|---|---|
| F5 | Debug ビルドしてデバッガ付きで起動 |
| Ctrl+F5 | Debug ビルドしてデバッガなしで起動 |
| Ctrl+Shift+B | ビルドのみ |

CMake Tools からプリセットを聞かれたら `default` を選んでください。

## ステージ（ブロック配置）の作り方

ブロックの並びは `levels/` フォルダのテキストファイルで指定します。

```
# ステージ 2: ピラミッド
....11....
...2222...
..333333..
.44444444.
5555555555
6.6.6.6.6.
```

| 文字 | 意味 |
|---|---|
| `1`〜`6` | ブロック（1 = 赤 60点 / 2 = 橙 / 3 = 黄 / 4 = 緑 / 5 = 青 / 6 = 紫 10点）。数字が小さいほど当たった音が高い |
| `.` または空白 | 空きマス |
| `#` で始まる行・空行 | 無視（コメント） |

- 1 文字が 1 マス、1 行が 1 段です。最大 10 列 × 14 段で、超えた分は無視されます。
- 配置全体は画面の左右中央に揃えて表示されます。
- 起動時は `levels/level1.txt` を読み込みます。別のファイルを遊ぶときは引数で指定します。

  ```powershell
  .\build\Release\breakout.exe levels\level2.txt
  ```

- ファイルが読み込めないときは、プログラムに組み込んだ既定のステージ（6 色の帯）で起動します。
- `levels/` はビルドのたびに実行ファイルの隣へコピーされます。編集したら再ビルド（VS Code なら F5）してください。

## ファイル構成

```
breakout/
├── CMakeLists.txt       ビルド設定
├── CMakePresets.json    構成プリセット（VS 2022 / x64 / vcpkg）
├── .vscode/             VS Code のビルド・実行設定
├── levels/              ステージファイル（ブロック配置）
└── src/
    ├── main.cpp         SDL の初期化・メインループ・キー入力・終了処理
    ├── Config.h         画面サイズ・速度・ブロック配置などの定数
    ├── Game.h           ゲーム状態・ブロック・Game クラスの宣言
    ├── Game.cpp         初期化・発射・移動・当たり判定
    ├── GameRender.cpp   画面描画
    ├── Level.h / .cpp   ステージファイルの読み込みと解析
    ├── Sfx.h / .cpp     効果音の生成と再生
    └── BallTexture.h / .cpp  球体ボールのテクスチャ生成
```

ゲームバランス（速度やブロックの大きさ）は [src/Config.h](src/Config.h) の値を変えるだけで調整できます。
